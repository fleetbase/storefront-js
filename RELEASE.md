> v2.0.1 ~ "Multi-value filters reach the API"

---

## Highlights

- Requires `@fleetbase/sdk` 2.1.1, which sends query lists in the bracket form PHP reads (`tagged[]=a&tagged[]=b`). With 2.1.0, multi-value parameters such as several store tags or several cart origins for a service quote reached the API as one value.
- The browser bundle is rebuilt with it.
- Publishing now waits for npm to serve the new version before verifying it.

No API changes from v2.0.0.
